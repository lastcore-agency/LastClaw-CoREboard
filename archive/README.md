# Archive

This directory contains legacy code, assets, and historical documents that are no longer active parts of the current LastClaw production implementation.

## Contents
- \`legacy-assets/\`: Old screenshots, design assets, and spritesheets from prior versions (e.g. coreboard-modern-motion-v3, visual-office-v2, and Six-SQUAD_character_web_pack).
- \`historical-docs/\`: Architecture specs and research notes (e.g. UI LASTCORE deep-research-report) retained for history.

## Rationale
These files have been moved here to keep the active repository root and \`src\`/\`server\` clean. They were proven unused by the current build, tests, and runtime references.
